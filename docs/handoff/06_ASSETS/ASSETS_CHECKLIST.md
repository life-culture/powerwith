# 06 · Assets checklist

Every file the site needs, where it comes from, and its status. Sophia supplies originals. The developer's build pipeline resizes, compresses and converts them. Never use screenshots or images saved from social media.

## How the files are shared

One shared Google Drive folder, owned by Sophia, named **Power With · Website Handoff**. The developer gets Editor access. Drive keeps original file quality, unlike email, messaging apps or Canva share links.

```
Power With · Website Handoff/
  01 Start Here/            this package, unzipped
  02 Brand/                 Brand System deck PDF, Canva view link, brand kit notes
  03 Wireframe/             live canvas link (shared by Sophia), plus 05_WIREFRAME files
  04 Images/
     Author Portraits/      full-resolution originals from the photoshoot
     Book Cover/            front cover, flat
  05 Icons and Logos/       SVG first, PNG fallback
  06 Documents/             privacy policy text, media kit when ready
```

## File naming

Lowercase, hyphens, no spaces. Number variants. Example `author-portrait-01.jpg`. Mark the preferred images in their names (`author-portrait-primary.jpg`, `author-portrait-secondary.jpg`).

## How to export from Canva

- **Deck as PDF.** Open the design, choose Share, then Download, choose PDF Standard, select all pages, download.
- **View link.** Share, then set the link to "Anyone with the link can view", copy it into `02 Brand/links.txt`.
- **Icons as SVG.** Open the icon design or the brand kit logo, choose Share, Download, then SVG. SVG download requires Canva Pro. Turn on "Transparent background" for PNG fallbacks.
- **Book cover.** Download the front cover page only, PNG, the largest size offered.
